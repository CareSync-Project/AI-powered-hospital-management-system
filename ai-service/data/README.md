# Dataset location

Training expects `Diseases_and_Symptoms_dataset.csv` in this directory. It is intentionally ignored by Git because the source CSV is approximately 46 MB.

Source: **SympScan - Symptoms to Disease**, Kaggle dataset `behzadhassan/sympscan-symptomps-to-disease`.

Published licence: **CC0: Public Domain**.

Download URL:

```text
https://www.kaggle.com/api/v1/datasets/download/behzadhassan/sympscan-symptomps-to-disease
```

Only `Diseases_and_Symptoms_dataset.csv` is used. Medication, diet, workout, and precaution files are not used because the application must not generate treatment or dosage advice.
